# EXTRAVAGANT — Render-powered luxury ecommerce starter

A premium black-and-gold storefront for eyewear, computers, phones and accessories.

## Architecture (no Supabase)

- **Render Web Service:** serves the HTML/CSS/JS storefront and runs the Node.js/Express API.
- **Render PostgreSQL:** stores products, administrator credentials and customer orders.
- **GitHub:** source-code repository and deployment source.
- **Customer accounts:** not required. Customers browse and place orders as guests.
- **Admin authentication:** one private administrator login, configured with Render environment variables.

## Features

- Responsive storefront and product categories
- Supplied eyewear photographs
- Shopping cart and guest checkout
- WhatsApp enquiries and order follow-up
- Product catalogue stored in PostgreSQL
- Admin login, add/edit/delete/hide products
- Admin order list and order/payment status management
- Server-side price lookup when orders are submitted

## Deploy on Render (recommended: Blueprint)

1. Create a GitHub repository and upload the contents of this folder.
2. In Render, choose **New > Blueprint** and connect the repository.
3. Render reads `render.yaml` and creates a Node web service plus a PostgreSQL database.
4. In the web service environment settings, set `ADMIN_EMAIL` and a strong `ADMIN_PASSWORD` (at least 14 characters recommended).
5. Set `WHATSAPP_NUMBER` to the store's full international number, digits only, e.g. `26097XXXXXXX`.
6. Deploy. Wait for `/api/health` to report `{"ok":true}`.
7. Open `/admin.html` and sign in using the admin email/password you configured.
8. Add the real product listings, prices and image URLs from the dashboard.

`JWT_SECRET` is generated by the Blueprint. `DATABASE_URL` is connected automatically to the Render PostgreSQL database. Do not put database credentials or JWT secrets in browser JavaScript or commit them to GitHub.

## Local development

Requirements: Node.js 20+ and PostgreSQL.

```bash
npm install
# Set DATABASE_URL, JWT_SECRET, ADMIN_EMAIL, ADMIN_PASSWORD
npm start
```

Open `http://localhost:3000`. The database tables are created automatically at startup. The initial admin is created from `ADMIN_EMAIL` and `ADMIN_PASSWORD` if that email does not already exist.

## Product images

The supplied images are in `images/`. Use paths such as `images/glasses-black-gold.jpeg` in the admin dashboard. For additional products, add image files to the repository and use their relative paths, or use HTTPS image URLs from a trusted image host. Render's local filesystem is not intended for permanent user uploads; use object storage if you later add image uploading.

## Payments

Checkout currently creates an order request and opens WhatsApp so the seller can confirm next steps. It does **not** initiate or automatically verify MTN MoMo or Airtel Money payments. Payment integration must be implemented server-side using approved merchant credentials and provider callbacks/status verification. Never put MTN/Airtel API secrets in frontend code. Do not mark an order paid until the payment is verified.

## Before going live

- Replace the sample WhatsApp number.
- Add actual product details, prices and photographs.
- Set a strong admin password and keep Render environment variables private.
- Add delivery, returns, warranty, privacy and terms pages.
- Review Render's current web-service and PostgreSQL pricing/limits. Free instances may sleep or have limited database retention/availability; check current plan details before relying on them for a live shop.
- Add rate limiting, backups and payment-provider verification before accepting live payments.
